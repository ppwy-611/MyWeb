    方法与适用范围

    分数从哪里来？

    页面连接当前七项 Ridge 回归模型，估计次晨 Groningen 睡眠质量总分（0–14，越高表示主观睡眠问题越多），再转换成更直观的体验指数。

    体验指数 = 100 × (14 − 模型估计分数) ÷ 14

    展示限制在 0–100 并保留一位小数；等级按页面显示的分数划分：80 分起为“舒适”，60 分起为“一般”，低于 60 为“较差”。这是原型展示规则，未经临床或等级数据验证。模型原始连续预测不截断。

    少填几项也能评估

    未提供的字段使用训练时保存的中位数填补。部分三项、四项组合接近完整输入，但任意组合不一定都有相同效果。完整七项的历史分组评估 MAE 约 2.49 分、RMSE 约 3.06 分（GSQS 尺度），高分段仍可能低估。

    分析报告如何生成

    报告根据 Ridge 对各输入的实际贡献与本地文字规则生成。参考输入为全部指标取训练中位数；缺失项不会被当作你的实测值进行解释。贡献反映模型中的关联，不等于因果或医学判断。第一版未调用大语言模型。

    数据与现实输入的区别

    模型训练数据来自 BSETS 研究中的客观睡眠测量。设备或自报数据的误差、单位与字段定义可能不同，现有表现不能直接保证日常应用效果；时间单位沿用项目目前按分钟理解的假设。
